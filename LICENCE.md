## 🧩 About

**Cabal Online Overlay** is a comprehensive mod menu for Cabal Online on Windows featuring a DPS tracker, auto-loot, inventory manager, skill cooldown notifier, and minimap enhancer.

Inspired by popular MMO overlays and community tools.

---

## ✨ Features

### ⚔️ Combat Tools
- DPS Tracker — monitor damage per second in real-time
- Skill Cooldown Notifier — visual alerts when skills are ready
- Auto-Target — automatically select nearest enemy
- Threat Meter — track aggro and enemy focus

### 🎒 Inventory & Loot
- Auto-Loot — automatically pick up items and currency
- Inventory Manager — sort, filter, and organize items
- Item Alert — highlight rare and valuable drops
- Quick Sell — sell junk items with one click

### 🗺️ Navigation & UI
- Minimap Enhancer — show NPCs, quests, and resource nodes
- Custom Overlay Menu — toggle features with a hotkey
- FPS Counter — performance monitoring
- Session Timer — track playtime and buff durations

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Insert"` | Toggle menu |
| `process_name` | String | `"CabalMain.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Restrict risky features |
| `auto_loot` | Boolean | `false` | Enable auto-loot |
| `dps_meter` | Boolean | `true` | Show DPS tracker |
